# quorum — совет моделей для исполнителя

Скилл для агентов, которые пишут код (Claude Code, Codex, Kimi, Grok). Исполнитель в трёх точках
задачи спрашивает совета у нескольких моделей разных семейств. Модели отвечают независимо в
одноразовых снапшотах репозитория, где могут читать код и запускать тесты. Судья из другого
семейства выбирает самое простое из корректных решений по явным критериям, а если знает решение
лучше всех предложенных, предлагает своё. Опровергатель обязан
опровергнуть каждое утверждение уликой из кода или тестом; что не опроверг, то и попадает
исполнителю.

Модели не спорят между собой. Спор по раундам ухудшает ответы, независимость плюс судья улучшает
(`references/method.md`).

## Как пользоваться

Пользователь пишет исполнителю: «реализуй SMSGATE-1121 и проси совета у codex, grok, glm».
Исполнитель спрашивает совета в трёх точках и не чаще:

1. **До кода**: план на полстраницы и одно место, где есть выбор. Судья выбирает вариант,
   исполнитель берёт его целиком вместе со списком «обязательно сделать».
2. **В середине, не больше раза**: тест падает, причина не понята с двух попыток.
3. **Перед «готово»**: советники сами запускают тесты, линтеры и e2e из брифа и называют только
   блокирующее; опровергатель отсеивает недоказанное; исполнитель чинит подтверждённое.

Одна точка без реализации: «спроси совет у codex, grok, glm: хранить статус в колонке или в
отдельной таблице». Судья: «судья opus» или `quorum config set QUORUM_JUDGE opus`. Модель и
уровень рассуждений задаются у каждого советника и у судьи: `--advisors grok@xhigh,codex=gpt-6.1-sol@max
--judge fable@high`.

```bash
quorum brief > /tmp/q.md               # шаблон брифа; заполнить (незаполненный consult не примет)
quorum consult --brief /tmp/q.md        # --stage plan|stuck|done, --advisors ИМЯ[=МОДЕЛЬ][@УРОВЕНЬ],…, --judge, --plan FILE
quorum wait RUN --max 110               # прогон идёт сам; первая строка ровно STATE: ready или STATE: running (позвать снова)
cat RUN/verdict.md
quorum feedback RUN "что помогло, что принято, что отклонено"   # без вердикта откажет
quorum clean RUN                        # --force останавливает прогон
```

## Что внутри вердикта

До кода и при сбое: кто есть кто (буквы судьи и модели), выбор судьи с таблицей по критериям
(буква советника или своё решение судьи), «обязательно сделать», «не брать», проверка выбранного
решения опровергателем, ответы советников с тем, что каждый отбросил.
На приёмке: подтверждено (чинить), опровергнуто (не чинить, можно вернуть рукой), не проверено
(решает исполнитель), вердикты советников.

## Стоимость

Codex, Grok, GLM и Kimi по подписке. Судья Fable читает три коротких ответа: около доллара за
вызов. Совет до кода: 15–60 минут, три подписочных прогона и один вызов судьи.

## Установка и настройки

`references/setup.md`. Проверка: `quorum doctor`. Офлайн-тесты: `tests/ci.sh`.

## Журнал

`~/.local/state/quorum/usage.jsonl` — события прогонов без текстов ответов: этапы, кто победил,
сколько находок подтверждено и опровергнуто, время и стоимость по ролям. `feedback.jsonl` —
заметки исполнителей. `quorum digest --since 2026-09-22` собирает всё в Markdown для ретроспективы.
